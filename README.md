# 📊 Excel Sales Dashboard Project

An interactive Excel dashboard designed to analyze and visualize sales performance across different regions, categories, and time periods.

---

## 🚀 Project Overview
This project showcases advanced Excel skills by building a dynamic and interactive dashboard using real-world data.

The dashboard helps in:
- Tracking sales performance 📈
- Identifying top-performing regions 🌍
- Monitoring KPIs and trends over time ⏳

---

## 🧰 Tools & Technologies Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers & Filters
- Data Cleaning Techniques

---

## ✨ Key Features
- Interactive dashboard with slicers
- Region-wise and category-wise analysis
- Monthly and yearly trends
- KPI indicators for quick insights
